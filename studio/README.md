# Preflight Content Studio

Standalone Sanity Studio for the Preflight learning app.

- Project: `4qoowg94`
- Dataset: `production`
- Local Studio: `npm run dev`
- Hosted Studio: https://preflight-content.sanity.studio/
- Schema deployment runtime: Node 24.18+ (`nvm use` in this directory)

## Commands

```sh
npm run dev
npm run schema:validate
npm run typegen
npm run build
npm run schema:deploy
```

Schema deployment requires a logged-in Sanity CLI session with access to the project, or a suitable `SANITY_AUTH_TOKEN`.

## Authoring and releases

Sanity is authoritative. `curriculumCatalog.current` owns ordered modules;
module, section, and lesson reference arrays own all lower-level ordering.
Stable IDs are app-facing database keys and must not change. Retire an entity
and remove it from its parent instead of deleting or unpublishing it.

```sh
SANITY_AUTH_TOKEN=... npm run catalog:export
npm run catalog:export:dry-run
```

`catalog:export` reads the complete published graph, filters retired entities,
validates every reference, and atomically writes the deterministic schema-v3
`../src/content/catalog.json`. Existing checked-in figures remain local for
offline use; new Studio figures use their Sanity CDN URL.

The weekly/manual GitHub workflow performs this export and opens a release PR
only when the generated bytes differ. On merge, `catalog:publish` uploads those
exact reviewed bytes and a checksum manifest, records an immutable
`contentRelease`, and atomically advances `curriculumReleasePointer.current`.
Only that non-sensitive pointer is written to the public `releases` dataset;
authored curriculum and reports remain in the private `production` dataset.

Validate the complete live dataset after an import:

```sh
npx sanity documents validate --workspace preflight --yes --level warning
```

`legacy:seed-catalog`, `export:bundle`, and `catalog:migrate` are retained for audit
history and one-time migrations. They are not part of normal authoring and must
not be used to push the repo snapshot back over Studio edits.
